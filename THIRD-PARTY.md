## Quest zone table

`QuestZones.lua` maps quest IDs to the zone where each quest is turned in. It is generated by `tools/gen_quest_zones.py` from the quest, NPC, object and zone data of pfQuest (https://github.com/shagu/pfQuest, commit 104f35678ca39ab1fb78b655f815cc7016f5e0c8), combined with the item data of the game client. pfQuest is licensed under the MIT licence below. Only quest-to-zone numbers are kept; no pfQuest code is included.
